## List of Protected Immovable Heritage of Republic of Armenia (WIP)

Dataset contains the merged list of protected immovable heritage in the Republic of Armenia, based on the published lists on Arlis.am as of May 2026. 

### Data Fields

| Field Name | Description                            |
| :--------- | :--------------------------------------|
| `province`     | Province                                   |
| `province_id`     | Province ID per Cadastre                                  |
| `community`     | Community                                   |
| `community_id`     | Community ID per Cadastre                                  |
| `settlement`     | Settlement                                   |
| `table`    | Table number in the decree                                  |
| `main_num1`      | Main number 1                                   |
| `sub_num2`      | Sub-Number 2                                    |
| `sub_num3`      | Sub-Number 3                                    |
| `sub_num4`      | Sub-Number 4                                    |
| `full_code`      | Unique code based on the table and heritage numbers                                 |
| `name`      | Name of the monument as present in the decree                             |
| `significance`      | Category of the monument as present in the decree 'Տ' for local and 'Հ' for governmental                      |
| `date`      | Date of the monument as present in the decree                         |
| `location`      | Location description of the monument as present in the decree                          |
| `notes`      | Notes as present in the decree                             |
| `revoked_act`      | Reference law article by which the item was removed                             |
| `legal_act`   | Reference law article |
| `type`      | Type of the monument (WIP generated by LLM)                          |
| `subtype`      | Subtype of the monument (WIP generated by LLM)                            |
| `comment`      | Comments left to mark some deviations from the legal code                         |
| `lon`      | Point coordinate of the feature WGS 84 (EPSG:4326)                        |
| `lat`      | Point coordinate of the feature WGS 84 (EPSG:4326)                        |

### Source & Coverage
Aggregated from official list Law published on governmental legal portal (arlis.am)

### Important Notes
Names and descriptions are present as in the law.
